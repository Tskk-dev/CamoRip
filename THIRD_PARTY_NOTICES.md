## Microsoft platform APIs and design references

Windows Media Foundation, the H.264 decoder transform, COM, and the virtual camera API are operating-system components. Apple AVFoundation, VideoToolbox, and Network.framework are iOS components. Their SDK/runtime terms apply.

The official https://github.com/microsoft/Windows-Camera sample was reviewed for virtual camera source activation and sample delivery. Preserve its MIT notice if any sample source is copied into this repository; see the native source's attribution for any reused portions. The new USB client implements the usbmux plist wire protocol and does not redistribute libusbmuxd or iproxy.

## Managed runtime and test dependencies

The Windows installer carries the self-contained .NET runtime and its third-party notices generated by .NET publishing. Tests use Microsoft.NET.Test.Sdk, xUnit, its Visual Studio runner, and coverlet.collector; see the test project for exact versions. These test dependencies are not shipped with the installed app.

No FFmpeg, libimobiledevice, or iproxy executable is required or distributed by the v1 build.
